# LLMFactory

This is a hobbyist project. No issues or tickets will be responded to. Code is subject to change without notice.

## Overview

LLMFactory is a python library that provides a unified interface for simple prompting of text, images and transcription AI.

## Supported Services:

### Text:
- Gemini
- Claude
- OpenAI
- Grok
- Deepseek
- OpenRouter

### Images:
- Imagen
- Dall-E

### Transcription:
- ElevenLabs (To Do)
